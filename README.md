# 🧠 Autonomous Resume Screening Agent

An AI-powered system that automatically screens, analyzes, and ranks resumes based on job descriptions using Natural Language Processing (NLP) and Machine Learning techniques.

---

## 🚀 Features

- 📄 Resume Parsing (PDF/Text extraction)
- 🧠 NLP-based skill matching
- 🎯 Job description similarity scoring
- 📊 Candidate ranking system
- ⚡ Fast and automated screening
- 📁 Scalable backend architecture

---

## 🛠️ Tech Stack

- Python
- NLP (spaCy / NLTK)
- Scikit-learn
- Pandas
- Flask / FastAPI (backend)
- Streamlit (optional UI)

---

## 📌 How It Works

1. Upload resumes (PDF/DOCX)
2. System extracts text from resumes
3. Job description is analyzed
4. AI calculates similarity score
5. Candidates are ranked automatically
