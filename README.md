# 🧠 Autonomous Resume Screening Agent

An AI-powered system that analyzes resumes against job descriptions and generates an ATS score using NLP techniques.

---

## 🚀 Features
- PDF Resume parsing
- Job description analysis
- Keyword-based ATS scoring
- Resume vs Job matching insights
- Supports PDF format resumes

---

## 🛠 Tech Stack
Python | FastAPI (optional upgrade) | NLP | Scikit-learn | PyPDF2 | Pandas | NumPy
